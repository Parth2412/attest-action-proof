# CH-04 claim-bearing validation scenario

This bounded public change exists to generate representative attest evidence for the `CH-04`
auditor interviews. A Codex session prepared the content, and the accompanying sidecar records
that self-reported Authorship Claim without storing prompt text.

The resulting Bundle is expected to bind the claim, the exact ChangeSet, the GitHub Actions
Signing Identity, and the forge-derived Review Record. It does not establish that the
self-reported claim is true, that the changed content is correct or secure, or that any framework
Control is satisfied.

No framework Control identifier is assigned here. Practising auditors reviewing the evidence are
asked which identifier, if any, they would cite and what additional evidence they would require.
